Reading the model

These are calculated rigid-link animations, not a flight or flexible-material simulation. Nominal checks use 3 mm stock; 6.35 mm plywood, actual actuator capacity and loaded operation remain unverified.

How this demo is updated

This site serves committed animation files. Hosting does not run Python or optimization. To regenerate locally, run python3 run_all.py demo, then commit and push the updated outputs/ files.

Drag to orbit in 3D, scroll to zoom, and use the playback controls to inspect individual poses. The 2D view includes an optional target overlay.
